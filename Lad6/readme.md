# Lab3 — Camera Processor (OpenCV C++)

## Requirements
- OS: Ubuntu 20.04+ (або будь-який Linux з apt)
- Camera: вбудована або USB
- CMake >= 3.10, GCC/G++ >= 9

## Install & Build & Run

git clone <your-repo-url>
cd Lab3
./preinstall.sh
./build.sh
./run.sh

## Keys
| Key | Mode |
|-----|------|
| 0   | Normal |
| 1   | Invert |
| 2   | Gaussian Blur |
| 3   | Canny |
| 4   | Sobel |
| 5   | Binarize |
| 6   | Arrows |
| 7   | Rotating Arrow |
| 8   | Zoom Arrows |
| 9   | Glitch |
| d   | Draw with mouse |
| z   | Zoom (mouse wheel) |
| c   | Crosshair |
| t   | Text Info (FPS, mean) |
| i   | Image Overlay |
| s   | Brightness slider |
| ESC | Exit |

## Mouse
- **Mode d**: ЛКМ drag = малювати лінії
- **Mode z**: Колесо миші = zoom
- **Mode c**: Рух миші = crosshair
