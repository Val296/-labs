Лабораторна робота №6 
C++ openCV 
Хід виконання роботи 
Створити C++ програму, яка в циклі: 
● Читає відео з камери. 
● Відображає його у вікні. 
● Реагує на натискання клавіатури та миші. 
дедлайн 9 травня 
● Вмикає різні режими обробки зображень в залежності від натиснутих клавіш. 
Вимоги: 
1. Використати openCV (інші бібліотеки за бажанням). 
2. Програма має мати модульну архітектуру (кожен модуль — окремий клас в 
окремих файлах .hpp та .cpp). 
3. Білд за допомогою CMake + make 
4. Зручний білд-скрипт (build.sh), в якому будуть міститись всі необхідні команди 
для компіляції 
5. Зручний скрипт попереднього встановлення (preinstall.sh), який буде 
містити всі команди, необхідні для білда і запуску вашої програми на іншому 
комп’ютері. Наприклад, встановлення бібліотек та білд системи: 
$ sudo apt install libopencv-dev cmake gcc -y 
6. Зручний скрипт запуску (run.sh), який буде запускати вашу програму 
7. В readme.md в директорії з програмою, описати інструкції для білду і запуску, а 
також вимоги до операційної системи та заліза. 
Я особисто перевірю, щоб Ваша програма білдилась і запускалась на чистій 
системі з першої спроби! Після git clone з вашого репозиторію я хочу запустити 
$ ./preinstall.sh 
$ ./build.sh 
$ ./run.sh 
і побачити успішний запуск. 
Приблизна архітектура: 
● клас CameraProvider - має поле cv::VideoCapture і метод getFrame(), 
що повертає cv::Mat з камери 
● клас KeyProcessor - обробляє натиснуту клавішу на клавіатурі (cv::waitKey 
повертає номер), і має містити enum з режимами 
● клас FrameProcessor - здійснює обробку зображень в залежності від режиму 
(enum з KeyProcessor). Режимів має бути декілька, можна проявити креатив. 
Кілька прикладів: 
○ Інверсія кольорів (bitwise_not) 
○ Gaussian blur 
○ Canny фільтр 
○ Фільтр Собеля 
○ Бінаризація, квантизація 
○ Відображення стрілочками 
○ Обертання стрілочками (плавне) 
○ Зум стрілочками 
○ Glitch effect (розсування каналів R/G/B у різні боки) 
○ малювати лінії, прямокутники мишкою (натискання і відтискання ЛКМ) 
○ Зум колесом мишки 
○ намалювати хрестик і пересувати стрілочками 
○ відображення тексту: лічильник кадрів, лічильник FPS тощо. Можна 
вивести на екран середню інтенсивність пікселів на всьому кадрі, або по 
каналах (RGB), або інші характеристики кадру 
○ картинка в картинці: перемістити по кнопці картинку з .png на зображення 
з камери
