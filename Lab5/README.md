Лабораторна робота №5 
Наука про дані: обмін результатами та початковий аналіз 
Окрім вирішення основного завдання дослідження, важливу роль відіграє обмін 
його  результатами. Корисно надати зовнішнім користувачам можливість працювати 
з  отриманими даними та візуалізувати їх у зручний спосіб.  
Одним із ефективних інструментів для цього в Python є бібліотека Streamlit, яка 
дозволяє  легко створювати веб-додатки з базовим та зручним функціоналом для 
роботи з даними  та їх візуалізації.  
Всю необхідну інформацію про роботу з Streamlit можна знайти за посиланням:  
https://docs.streamlit.io/get-started  
Хід виконання роботи  
Створення веб-додатку із використанням модуля Streamlit:  
● Створіть dropdown список, який дозволяє вибрати часовий ряд VCI, TCI, VHI 
для  набору даних із лабораторної роботи 2;  
● Створіть dropdown список, який дозволяє вибрати область, для якої буде  
виконуватись аналіз;  
● Створіть slider, який дозволяє вибирати інтервал тижнів, за які відбираються 
дані;   
● Створіть slider, який дозволяє вибрати інтервал років, за які відбираються 
дані;  
● Створіть button для скидання всіх фільтрів і повернення до початкового стану 
даних (відповідно інтерактивні елементи повинні мати початкові значення);  
● Створіть три вкладки для відображення таблиці з відфільтрованими даними, 
відповідного до неї графіка та графіка порівняння даних по областях.  
● Перший графік повинен відображати відфільтровані дані (часові ряди за 
діапазон  
років, що обмежені інтервалом тижнів). Другий графік має 
відображати порівняння  значень VCI, TCI або VHI (залежно від обраної опції 
у списку dropdown) для обраної  області з усіма іншими областями за 
вказаний часовий інтервал. Продумайте вигляд і функціонал цих графіків.  
● Створіть два checkbox для сортування даних за зростанням та спаданням 
значень  VCI, TCI або VHI (залежно від обраної опції у списку dropdown). 
Продумайте реакцію  програми, якщо увімкнені обидва чекбокси.  
● Інтерактивні елементи мають бути розміщений в одній колонці, а графіки з  
таблицею — в іншій.
